# Intelligent Cloud Resource Validation Tool

## Overview

An AI-powered cloud security validation platform that scans Terraform Infrastructure-as-Code (IaC) files using Checkov and OPA, classifies security violations using AI, generates remediation guidance, and produces compliance reports.

## Tech Stack

- Python
- Terraform
- Checkov
- OPA
- LangChain
- Groq
- Gemini
- Streamlit
- GitHub Actions
- Pytest
